# RNA-seq Analysis of Host Transcriptional Responses to *Rhizopus microsporus* Infection and Doxycycline Treatment

This repository contains the complete R code used for the transcriptomic analyses described in:

> **Doxycycline attenuates systemic inflammation, leukocyte migration, and regulated cell death during mucormycosis**  
> *(manuscript in preparation)*

---

## Overview

Bulk RNA-seq data from four organs (liver, lung, spleen, and brain) of mice under three conditions:

| Group | Description |
|-------|-------------|
| `Noinf` | Non-infected controls |
| `Notra` | Infected, untreated |
| `Dox` | Infected, doxycycline-treated (aCT) |

The analysis covers:
1. Count matrix assembly and normalization (DESeq2/VST)
2. Multivariate ordination (PCA, RDA, PERMANOVA)
3. Differential expression and volcano plots
4. GO and KEGG pathway enrichment
5. Attenuation Index for RCD, inflammation, and migration
6. GM-CSF signaling analysis


Key packages: `DESeq2`, `vegan`, `ggplot2`, `ComplexHeatmap`, `circlize`, `clusterProfiler`, `org.Mm.eg.db`, `dplyr`, `ggpubr`

## How to reproduce the analysis

Run scripts in order from within R or RStudio. Each script is self-contained and saves its outputs to the working directory.

```r
# 1. Install packages (once)
source("01_preprocessing/00_install_packages.R")

# 2. Build metadata
source("01_preprocessing/01_create_metadata.R")

# 3. Normalize counts
source("01_preprocessing/02_counts_to_vst.R")

# 4–10. Run remaining analyses in order
```

All scripts expect `vst_matrix` and `metadata` to be present in the R environment, generated by `02_counts_to_vst.R`.
